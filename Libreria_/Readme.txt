📚 Sistema de Gestión para Biblioteca
Aplicación web desarrollada como práctica académica utilizando tecnologías web modernas para gestionar y filtrar información de una biblioteca.

🚀 Funcionalidades
Consulta de libros.
Filtrado de información.
Interfaz amigable para navegación.
Organización de contenido bibliográfico.
🛠 Tecnologías
Spring Boot
Java
HTML5
CSS3
JavaScript
🎯 Objetivo
Aplicar conceptos de desarrollo web full stack mediante la construcción de una interfaz para consulta y filtrado de información bibliográfica.
